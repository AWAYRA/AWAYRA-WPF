- Truthfully stating that a project is based on or compatible with Awayra

- Using the name Awayra in reviews, tutorials, comparisons, and other descriptive references

Written permission is required to:

- Distribute a modified build under the name Awayra

Forks and modified distributions should use a clearly different name and visual identity and must state that they are unofficial.
