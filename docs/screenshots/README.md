# Screenshot provenance

Captured from the official installed Awayra 1.3.1 Windows application on 2026-10-08.
Window chrome, unused desktop and margins were cropped. App controls, text and counts were not redrawn.

The captures cover the dashboard, full settings, eye and movement overlays, pause/resume, About/Support and all four settings groups.
Eye: 20 minutes / 20 seconds. Movement: 45 minutes / 60 seconds.
Example preferences: Still water, volume 15%, repeat 5 seconds, idle reset 7 minutes.
Solid overlay background was used during capture; the user's original clarity was restored afterwards.
