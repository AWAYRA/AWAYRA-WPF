# Screenshot provenance

Captured from the actual running Awayra 1.3.2 WPF interface on 2026-10-08.
Each view was rendered directly to a lossless PNG at 3x resolution / 288 DPI.
There are no JPEG intermediates, bitmap upscaling or recreated controls. Native window chrome and desktop surroundings are excluded. The overlay shadow is omitted so it cannot rasterize text at monitor resolution.
The same original PNG bytes are used in this repository and on the website.

The captures cover the dashboard, full settings, eye and movement overlays, pause/resume, About/Support and all four settings groups.
Eye: 20 minutes / 20 seconds. Movement: 45 minutes / 60 seconds.
Default preferences: Soft bell, volume 15%, repeat 2 seconds, idle reset 5 minutes, snooze 5 minutes, sound disabled.
Solid overlay background was used for readable documentation. Capture settings and statistics were isolated from the user's application data.
See `manifest.json` for dimensions, capture method, source revision and SHA-256 checksums.
